# 从像素到机器人平面坐标

本库不把像素值当作机器人毫米坐标。当前已按用户授权提供 LR41 名义尺寸估计模式，见 [直接启动](../../examples/button_battery/README.md)。它能输出工作平面毫米坐标；相机内参、机器人对应点和基座高度以后可用实测值替换。

适用条件：相机和机器人基座关系固定、电池平放于同一已知平面、姿态近似正视。手持相机/眼在手上且拍照位姿变化时，需要上层根据机器人位姿和手眼标定计算变换。堆叠物料或高度变化需要额外深度信息。

## 获取标定

1. 固定拍照位姿、焦距和分辨率。镜头畸变明显时，用棋盘/标定板得到 `camera_matrix` 与 `distortion`；本接口对点进行去畸变。
2. 在**电池待抓取表面同一高度**布置标定点，覆盖整个取料区。记录至少 4 个非共线图像中心 `[u,v]` 及其实际机器人基坐标 `[x_mm,y_mm]`。建议 9 个或更多，含四周和中部。顺序一一对应。
3. 独立测量 `plane_z_mm`，填入机器人坐标系名称。不要用电池型号或目测板宽猜测标定。
4. 写入总仓库本地 `points.json`，调用下面命令；保留原始对应点及镜头/机器人/日期/拍照位姿元数据。
5. 使用**未参与拟合**的点验证误差，达到工艺容差后再接机器人。先验证单位、轴向、目标中心，再在上层实施抓取验证。

格式示意（以下全为合成演示数值，不能用于当前现场）：

```json
{
  "pixels": [[100,100],[900,100],[900,700],[100,700],[500,400]],
  "xy_mm": [[0,0],[160,0],[160,120],[0,120],[80,60]],
  "image_size": [1920,1080],
  "frame_id": "robot_base",
  "plane_z_mm": 25,
  "max_error_mm": 0.5
}
```

```bash
industry-cv calibrate /path/to/site/points.json --output /path/to/site/plane.json
industry-cv stream --config /path/to/site/vision.json \
  --calibration /path/to/site/plane.json --frames 120
```

有镜头标定时，为 points.json 添加 `camera_matrix`（3×3）和 `distortion`（4/5/8/12/14 项），必须同时提供。所有像素点及 ROI 都使用原始图像坐标，内部只对投影点去畸变；不要再给已经去畸变的图像重复应用该标定。

拟合使用全部点并检验每个残差，不通过随机剔除坏点来隐藏错误测量。4 个点可产生近乎零残差，这**不能证明**物理定位精度。拟合点凸包之外不输出位置，分辨率改变拒绝投影。改动相机、焦距、拍照位姿、机器人基座关系或目标高度后，重新标定。

对于大视角倾斜，椭圆图像中心不等于真实圆心的严格投影；当前检测器以较高轴比限制倾斜程度。精密应用需要近正视成像与独立定位精度实验，或扩展到整平图像/圆锥曲线姿态算法。

## 用独立点验收坐标

拟合后的文件保存 `fit_pixels`，用于检查验收位置是否重复使用拟合位置。另行测量未参与拟合的点，写入 `validation.json`。建议覆盖中心、四周、实际抓取区域，数量和允许误差按现场工艺确定。

```json
{
  "pixels": [[300,250],[700,250],[500,550]],
  "xy_mm": [[40,30],[120,30],[80,90]],
  "image_size": [1920,1080],
  "frame_id": "robot_base",
  "plane_z_mm": 25,
  "max_error_mm": 0.5
}
```

上面的数值仅用于配合前面的合成示例演示，必须替换为真实独立测量。

```bash
industry-cv validate-calibration /path/to/site/validation.json \
  --calibration /path/to/site/plane.json --output /path/to/site/validation-report.json
```

输出逐点期望/预测 XY、毫米误差、RMSE、最大误差、允许误差、坐标系和标定内容 SHA-256。此命令不重新拟合，不修改原标定。坐标系、平面高度、分辨率不同或点越界时报告输入错误；同一误差集不跨坐标系比较。

退出码 0 表示所提交点均在容差内，且未复用拟合位置；退出码 3 表示验证未通过，报告保留具体原因；退出码 2 为输入错误。默认距任何拟合点不足 1 像素的验证点视为复用，可用 JSON 的 `min_separation_px` 显式设置。旧标定文件若没有 `fit_pixels`，仍可做投影，但无法证明验证位置独立，报告不会通过；用保存的真实原始对应点重新拟合后再验证。

位置不重复只是独立测量的必要条件。工具不能证明机器人坐标确实由独立测量获得。通过结果仅覆盖这些样本点的 XY，不能证明整片工作区、Z、高度误差、TCP、图像识别或实际抓取成功。上层应将报告与原始对应点、当前相机安装状态及工艺要求一并使用；验证不会自动改变 `VisionPipeline` 的视觉 `pickable` 结果。
