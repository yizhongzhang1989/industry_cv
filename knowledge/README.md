# 工业现场知识库

每个现场先在总仓库积累数据和运行记录，将有复用价值的部分带回本仓库。新的记录与算法改动一起评审，使结论能够被测试和复现。

一条现场记录应包含：任务与适用边界；相机/光学/光源/分辨率；物料与背景；样例来源和标注方式；成功与失败条件；最终配置；准确率/召回率/定位误差/时间的测量方法；复现命令；相关算法版本；仍未验证的问题。

真实数据优先保留最小、必要且可共享的回归样例。凭据、内部网络拓扑、客户个人或业务信息不进入通用数据集。本站点完整采样暂存于被忽略的 `artifacts/`；需要长期保存的现场数据由总仓库管理。

变更流程：现场问题 → 可复现样例 → 可复用算法/配置/技能改进 → 测试与证据 → 更新知识条目 → 上层更新子模块。不要只保存“某个参数有效”的结论而丢掉成像条件，也不要把某现场 ROI 当作所有场景的默认工作区。

已记录：[2026-11-26 纽扣电池识别](cases/2026-11-26-button-battery/README.md)。

## 组织与回流

每个案例使用 `cases/YYYY-MM-DD-场景名/README.md`；同一案例的图片放 `images/`，测量记录放 `metrics/`。算法测试使用的最小原图放 `tests/data/<能力>/`，避免在知识目录再复制一份原图。

使用 [案例模板](CASE_TEMPLATE.md)记录可复現条件，新增案例后更新本页索引。可复用的参数进入包内 profiles，算法进入对应能力模块；只有现场成立的 ROI、相机地址和工具位姿留在案例或总仓库中。技能只链接这些已维护的来源。
