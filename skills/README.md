# AI 技能索引

技能负责引导 AI 使用本库的确定性接口与现场知识；算法实现保留在 Python 包中，不在技能内复制。

| 技能 | 适用任务 | 实现与依据 |
|---|---|---|
| [button-battery-vision](button-battery-vision/SKILL.md) | RTSP 纽扣电池检测、定位、验证与回流 | `industry_cv.detectors` / `pipelines`，LR41 案例 |

将本仓库作为子模块引入后，让所用 AI 工具读取对应 `SKILL.md`，或按该工具的机制关联技能目录。技能中的相对路径以本仓库为依据，应保留可解析的完整目录关系；仅复制一个孤立 SKILL.md 会丢失文档和代码引用。

添加新技能时，描述明确的能力和触发任务，链接实际实现、命令和案例；不把当次会话的权限或现场默认值变成其他项目的全局要求。新增后更新此索引。
